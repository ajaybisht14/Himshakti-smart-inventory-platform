# Himshakti-smart-inventory-platform

An AI-enabled platform for inventory management, production optimization, and direct-to-consumer sales for HimShakti Food Processing Unit.

## Tech Stack

* Frontend: Next.js
* Styling: Tailwind CSS
* Backend: FastAPI
* Database: PostgreSQL
* Authentication: JWT Authentication
* Deployment: Vercel + Render
* AI API: OpenAI API

## Features

* Batch and expiry tracking
* Production optimization dashboard
* Packaging cost analysis
* D2C e-commerce portal
* Sales and inventory analytics
* AI-powered shelf-life prediction
